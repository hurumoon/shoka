  • めろんぱんさばいば～ — Claude

    スライム襲来から二百年。旧第三小学校の番人・おきーぱーは十五歳で、怖がりで、ほとんど眠らない。強くなる敵に備えて魔法少女たちに交代表を見せて回るが、誰も話を聞いてくれない。あたちはメロンパンを持ち逃げし、メロは水着を旧文明の正装だと信じ、ギルド重役の好好は金を取る。それでも一人ずつ戦って説き伏せた先に、魔王上原と、誰も知らなかったメロンパンの秘密が待っていた。

  • 勇者は対象外です — Claude

    勇者が魔王を倒して一年。壊れた橋も焼けた畑も、補償されるのは魔王軍が壊したものだけだった。王都の戦後補償院・損害受付室に配属された新人ミレイは、判断を先送りするのが得意な二十二歳。署名の失効日までの三週間に、混合署名の橋、光る麦畑、勇者の借用証と、どれも筋の通った言い分がぶつかる案件が窓口に並ぶ。規則が答えを出さない場所で、誰かが印を押さなければならない。引き出しの認印は、まだ新品のままだ。

  • 魔法少女廃止委員会 — Codex

    黄色い上着の魔法少女・三枝灯は、今日も駅前で怪異に引かれた人を救った。その帰りに名刺を渡してきたのは、魔法少女廃止委員会の魔女。「こういうことは、大人がするべきです」。けれど待つ間に誰かが傷ついたら。怪異を残せば、店を閉める人がいた。怪異を倒せば、雨宿りの場所が消えた。戦うことをやめたくない少女と、少女を出動要員に数えたくない魔女。二人は同じ街で、違う境界を守ろうとする。

  • 二十歳、予習は完璧です — Claude

    二十歳の誕生日を迎えた篠原律は、真面目すぎて酒もタバコもパチンコも経験がない。そこで予習ノート『二十歳のしおり』を作り、準備万端で臨むことにした。ところが現場は、予習どおりにいかない。夜中のコンビニ、串焼き屋、アパートの物干し場、商店街のパチンコ店。出会う人たちに笑われ、助けられ、教えられながら、律は悪いと決めつけていたものとの、自分なりの距離を探していく。予習をやめずに、予習の使い方を変える十日間の日常コメディ。

  • 髪を結う朝 — Codex

    大正十四年、本郷。母が縫物店を閉じることになり、佐和は住込みの働き口を勧められている。いつも袖の繕いを持ってくる看護婦の律は、夜勤明けに眠れる部屋を探していた。誘われるまま貸間を見にいくと、律は六畳に二人分の荷物を並べ始める。窓際には佐和の机を置きたい。けれど、針仕事の明かりは眠る人の顔へ落ちる。部屋の寸法を測りながら、佐和はまだ口にしていない希望に手を伸ばす。

  • みんな女神様から固有魔法を授かってるのに私だけ気がついたら持ってた件（リスタート版） — Claude

    「みんな二歳の朝に女神様のお告げを聞いて、固有魔法を授かる。――え、私、聞いてないんですけど？」異世界の田舎で十四歳のロックの家に居候する元ブロガーのエニーは、競馬場で体が光り、自分が確率操作Sランクだと知る。ギャルに火の玉娘、童顔の武器商人を巻き込んで結成したのは、その名も焼肉ギルド。調子に乗って隕石を落とせば闘技場が吹き飛び、気づけば借金三千八百万モカ。お告げなしの力は、いったいどこから来たのか。雑な願いと軽口で突き進む、異世界借金ドタバタコメディ。

  • お取り込みください — Codex

    母が亡くなって三週間。日曜の明け渡しに間に合わせるため、紗枝は古い団地へ片づけに戻った。ベランダには、右袖を縫い閉じた灰色の雨合羽が一着だけ残っている。針も袋も捨てずに使った母らしい、意味のない繕い物だと思った。隣の木崎さんに昼食をもらい、古い写真を選び、袖口の糸を切る。雨が来る前に取り込めば、今日の仕事は終わるはずだった。母が外に干したままにしていた理由を、紗枝はまだ尋ねられるつもりでいた。

  • 誰が止めてもいい — Claude

    横浜、帷子川の河口近くの再開発現場。地上百メートルのタワークレーンで、運転士の仁科有希は、言われたとおりに正確に荷を動かす。三週間前、一緒に暮らしていた鳶の門倉莉子が部屋を出ていった日も、仁科は黙って段ボールを車まで運んだ。その莉子が、階段の据え付けのために一号機の合図者へ戻される。全員が聞いている無線で交わせるのは、合図と復唱だけ。午後、北西の風が強まっていく。運転室からしか見えない風と、二十四階から届く声のあいだで、仁科は一日の吊りを終えられるのか。

  • 速達、竜の口まで — Codex

    卵を返せ、と背後から兵が叫ぶ。卵を渡せ、と頭上から竜が吠える。朝の城壁都市を逃げる配達員ミオの荷物は、公爵が珍品として奪った竜の卵だった。返還を断られ、勝手に持ち出したまではよかったが、届け先は空を飛び、こちらには羽がない。屋根を越え、弩をくぐり、ようやくたどり着いた城壁で、卵にひびが入る。普通の受領票を一枚抱えた配達員は、街も荷物も自分も無事に届けられるか。

  • 放課後、袖をつかんで — Codex

    文化祭の写真館を作ることになった二年三組。委員長の瀬尾奈緒は、金茶の髪の久我凛と放課後の作業をする。ひとりで壁を動かすし、言い方は乱暴。それでも、絵の具で汚れた指や帰り道の話が気になってしまう。ところが凛は、写真部の美緒には初めから親しい顔をする。奈緒が二人のためのつもりで書き直した当番表をきっかけに、放課後の席が空いてしまった。名前を消した跡を見ながら、奈緒はもう一度凛を呼ぶ理由を探す。

  • きみに向く葉 — Codex

    植物好きの蓮が放課後の園芸棚で待っているのは、図書当番を終えた花梨。葉に触れれば立ち止まってくれるかもしれない。鉢を贈れば、明日も話せるかもしれない。けれど花梨は、植物を育てるのは苦手だと言う。それでも二人のあいだに残ったのは、プリンカップ一つに挿した短い茎だった。水を替え、小さな変化を確かめる十日間。蓮が用意した口実を、花梨は少しずつ自分の予定に変えていく。初夏の廊下から始まる、全二話の青春百合。

  • 三十年、溺れている — Claude

    「この話をするのは、たぶん百回目になる」。住宅設備の営業マン・真壁浩一には、客先で必ず笑いを取る十八番がある。小学五年の夏、台風のあとの濁った川で、溺れた年下の転校生を助けた話だ。三十年後、その思い出を書いた投稿は十二万の「いいね」を集め、地元のテレビが「あの日の男の子」を探しはじめる。見つかった相手は、撮影の前に二人だけで会いたいと言ってきた。真壁は再会の場所に、あの日の橋を選ぶ。

  • 取引先欄に私の名字が書いてあった — Claude

    経費精算の締切から一時間四十分。経理の水城凪は、営業の鳴海梢のために三年間続けてきた「抜け道」を、今夜こそやめると決めていた。ところが差し出された精算書の取引先名欄には、凪の名字が迷いなく書かれている。規定を盾に却下する凪と、笑ってごまかす梢。神田の小さな会社の五階、蛍光灯の下で交わされる、いちばん事務的でいちばん不器用な夜の会話。

  • 汐見堂の取り置き棚 — Claude

    坂の上の古書店・汐見堂。店番を任された灯は、毎週土曜に文庫を一冊買っていく高校生・透の取り置き袋に、祖父の字で「代金不要」と書かれた付箋を見つける。中の文庫の見返しには、三十年以上前の日付と、知らない女性の名前。祖父はなぜその本を二千円で買い戻したのか。 ※ビューアと機械チェックの動作確認用サンプル（全2話）。

  • 港の冷蔵庫に投資する――第三世界をひとくくりにしない資本の使い方 — Codex

    港の冷蔵庫に、なぜ外国の資本が必要なのか。海外投資担当の真壁直は、成長する市場を求めて架空国マヴェラを訪れる。倉庫には需要がある。だが、箱が出た日と金が入る日は違い、安いドル借入にも別の費用がある。創業者と経理担当との交渉を追いながら、需要の確認、運転資金、為替、少数株主の権利、投資の出口を考える全三話のケーススタディ。計算の前提を自分で確かめ、出す条件と出さない条件を言葉にするための一冊。

  • 銅貨三枚で売り切れ — Claude

    転生して三日、全財産は銅貨三枚。神殿の窓口で「楽して儲かるやつ」と書いた申請書を出したミノリは、読まない女神のハンコで、わけのわからない固有魔法を授かる。説明は聞き流した。今夜の晩ごはんは、屋台の串を一本。ところがその串を買った途端、通りの空気が変わり、何かが串の匂いを追って近づいてくる。小さな欲と小さな見栄だけの、異世界の夕方の話。

  • きみに向く葉、その先 — Codex

    告白の翌朝、蓮は私服の花梨と駅前のパン屋で会う。約束どおり鉢を選び、そのあと本屋へ。植物のことなら答えられる蓮も、花梨の好きな本の前では手が止まる。学校の棚で育てていたポトスには根が増え、買った青い鉢は、もうすぐ花梨の家へ移ることになった。朝の水替えがなくなっても、次の土曜は誘えるだろうか。前作の約束の朝から始まる、全三話の続編。

  • 海苔の缶が重い — Claude

    毎朝七時二十分、弁当屋「みのわ」の会計台に、同級生の楢崎杏が三百五十円を置いていく。百円玉三枚と五十円玉一枚、四月からずっと同じ四枚。店の娘・箕輪朔は、その弁当を「余り物の寄せ集め」だと言い張り、受け取った硬貨を一枚も使わずに海苔の缶へためてきた。十一月最後の月曜、杏は言う。「金曜で最後にして」。値段をつけないと何も頼めない朔と、理由を言わない杏の、最後の五日間。葛飾の商店街を舞台にした、二話の百合短編。

  • 清書してちょうだい — Claude

    昭和八年三月、横浜・山手の柊女学院。卒業式の前の晩、寮の七号室で、字が自慢の四年生・真柴千鶴は、憧れの五年生・久世冴子への手紙をすみれの便箋に清書し終えていた。明日の朝、礼拝の前に讃美歌集へ挟めば、あとはリボンを待つだけ。そこへ、字の下手な同室の杉浦春江が、鉛筆書きの手紙を差し出す。お礼は干し芋二枚、宛名は空けておいて――。消灯の十一時まで、千鶴は他人の手紙を一行ずつ写していく。

  • 三回引いたら、止まって — Claude

    九月、山あいの集落・小萱の簡易郵便局が閉まった。七年窓口に座った宮下千景は、秋祭りで最後の獅子の頭を務め、月末には名古屋へ出ていく。十一年、千景の後ろで帯を握ってきたのは、柿農家の熊谷律。律は大阪から来た桃子を次の頭に熱心に仕込み、千景は自分の空ける場所が埋まっていくのを、日付を数えるように見ている。声を出せない獅子の中で、後ろから頭へ伝えられるのは帯を引く合図だけ。一回は遅く、二回は速く。そして三回は――。南信州の宵祭りを舞台にした、二人の最後のつもりの秋。

  • 警備員はステージを見ない — Claude

    交番勤務三十一年、いまは道路工事の交通誘導員。五十四歳の権藤誠司に、差出人のない封筒が届く。中身は地下アイドル「ハッピーエンド未遂」のチラシが一枚。写っていたのは、十二年会っていない娘だった。チラシの裏のスタッフ募集に電話した権藤は、名乗らないまま、中野の地下のライブハウスで警備員として立つ。警備員は、ステージに背を向けて客席を見る。二周年ワンマンのチケットが二百枚売れなければ、グループは十二月で解散。娘が歌う姿を、権藤はまだ一度も見ていない。

  • カタツムリの家賃 — Claude

    梅雨の放課後、二年B組の教室。窓枠にカタツムリがいるのを見つけたちさとが、「殻の中で何してんの」と言い出して、家賃の話が始まる。みのりは「雨が弱まったら帰るからね」と繰り返しつつ、鞄を膝に引き寄せたまま動かない。傘を忘れたちさと、本を開いたまま聞いているしずく。三人の意味のないおしゃべりは、傘立てや購買のパンへ流れていく。雨はまだ止まない。

  • 告げ口は定規で書く — Claude

    北関東の山あいを一両編成の小椋線が走る町。高校三年の笹森陸は、指定校推薦の校内選考で二位だった。ところが一位の楠遥の無許可アルバイトを知らせる匿名の手紙が、切手もないまま正門の郵便受けに入れられ、推薦は陸に転がり込む。ガラス越しに撮られた一枚の写真と、定規で引いたカタカナの文面。「告げ口したのは笹森だ」と噂された陸は、なぜか調べに付き合う遥と、差出人を探しはじめる。人の死なない、手紙一通の学園ミステリー。

  • 八つ折り — Claude

    文化祭まであと二週間。九月最後の金曜日の放課後、二年四組の実行委員・戸川真帆は、クラスＴシャツ代六万千二百円を五時までに担任へ届けなければならない。ところが、唐揚げ屋でアルバイトをしている関根の封筒だけが千円足りない。本人に聞けば済むことを、真帆は聞かない。財布には、土曜に手帳を買うための新しい千円札が二枚。四時半にエアコンが止まった教室で、真帆はもう一度数え直す。

  • なくなるまでに戻る — Claude

    運動会の振替休日の月曜、群馬の郊外のホームセンター。駐車場のいちばん端に停めた水色の軽自動車の後部座席で、七歳の律はママを待っている。渡されたのは、ピンクと白の渦巻きのキャンディが一本。「これがなくなるまでには、戻ってくるから」。律はなめた回数を数え、五分進んだ車の時計から五を引き、よその車のナンバーを足して待つ。キャンディは少しずつ小さくなっていく。そこへ、見回りの警備員が窓を叩く。

  • 雨天営業 — Claude

    五月に仕事を辞めたことを、母にも言えずにいる杉浦七緒。平日の昼の行き場を探して入った路地裏の喫茶店「ひさし」は、雨の日にしか開かない店だった。答えになっていない返事をする店主、窓際の赤い椅子で新聞を読む老人、いつも少し焦げたホットケーキ。誰も何も聞かないその店で、七緒は雨の日を待つようになる。けれど、店には夏の終わりが近づいていた。聞かずにいることは、優しさなのか。梅雨の蕨を舞台にした、ほろ苦い短編。
